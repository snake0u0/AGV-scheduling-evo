# discussions

`/dh-discuss`가 만드는 문답 기록. 문서 하나(카드·보고서·블로그 리뷰)를 놓고 LLM이 캐묻고,
내가 대답한 결과를 남긴다. 파일명은 `YYYY-MM-DD-<주제슬러그>.md`.

`docs/reports/`와의 차이: 보고서는 **실험이 무엇을 보여줬는가**, 여기는 **내가 그걸 어떻게
이해했는가**다. 대답하지 못한 질문은 `아직 모르는 것`에 그대로 남긴다 - 그게 다음에 읽을 목록이다.

이 폴더는 SecondBrain-hub의 `scripts/scan-sources.sh` 감시 대상이라, 다음 `/update-wiki` 실행 때
후보 목록에 뜬다. 다만 **문답을 했다는 것만으로 wiki에 올라가지는 않는다.** 게이트에서 내가 고른다.
