# 보고서 - 재현성 캠페인: 통찰은 재현되나 "양쪽 다 유의하게 이김"은 재현 안 됨

작성 2026-07-24. 선행: `2026-07-24-main-campaign.md`(단일 진화가 D1/D2를 유의하게 이김).
원칙 유지: 데이터 변형 금지, **결과 부풀리지 않음(특히 자기 이전 결과에 대해서도)**.

> **[중요 정정 2026-07-24 후속] 이 보고서의 비관적 양적 결론("D1 우위 재현 안 됨, 양쪽 다 1/3")은
> 교란이었다.** 여기서 쓴 가벼운 평가 예산(GA 60x60/시드2)의 노이즈 탓. 동일 규칙들을 적정 예산
> (70x70/시드3)으로 재평가하니 **4개 중 3개가 D1·D2를 양쪽 다 p<0.01로 이김**. 반드시
> `docs/reports/2026-07-24-confound-removal-reeval.md`와 함께 읽을 것. 양적 결론은 그 보고서로 대체됨.
> **단 질적 발견(machine_free 3/3 재현, max-결합 2/3)은 그대로 유효.**

## 결론 (한눈에)

- **재현성 캠페인을 돌린 게 잘한 일이다.** 본 캠페인의 headline("P가 D1·D2를 양쪽 다 p<0.01로 이김")은
  **독립 진화 3회에서 robust하지 않았다**. 정직하게 하향 조정한다.
- **질적 통찰은 재현된다(강함)**: 독립 진화 3회 모두 `machine_free`를 규칙에 포함했고(3/3),
  핵심 결합 통찰 `max(arrival, machine_free)`(또는 수학적 등가형)이 2/3에서 재등장. LLM이 **"공정 시작은
  도착만이 아니라 기계 가용에도 묶인다"는 원리를 run마다 독립적으로 재발견**한다. 이건 논문 가능한 발견.
- **양적 우위는 혼합(약함)**: D2는 3회 중 2회 유의하게 이김(+1회 경계). **D1은 3회 중 1회만 유의**.
  "양쪽 다 p<0.05"는 3회 중 1회(P2)뿐. 본 캠페인의 강한 결과는 운 좋은 단일 run이었다.
- 단, **평가 예산 교란 있음**: 이번 test는 본 캠페인보다 가벼움(GA 60x60/시드2 vs 70x70/시드3).
  가벼운 GA가 노이즈를 키워 D1 우위를 일부 씻었을 수 있음 - 후속으로 동일 고예산 재평가 필요(§4).

## 1. 설정

독립 진화 3회(LLM은 확률적이라 매번 다르게 탐색) -> 나온 규칙 3개(P1/P2/P3)를 D1/D2와 함께 **동일
test 세트 33인스턴스**로 일괄 비교(GA 60x60, 시드 2개). train은 본 캠페인과 동일(01a@2,13a@2,07a@4).
전체 52분, CLI 18회.

## 2. 진화된 규칙 3종 (재현성의 핵심)

| run | 규칙 | machine_free 사용 | max-결합 motif |
|---|---|---|---|
| P1 | `-arrival - 0.5*empty_travel - 0.2*machine_free/(agv_free+1) - 0.1*agv_cum_travel/(agv_free+1)` | O | X (나눗셈 형태) |
| P2 | `-(arrival + 0.7*empty_travel + 0.1*wait) - 0.3*max(0, machine_free-arrival)` | O | **O (등가형)** |
| P3 | `-max(arrival, machine_free) - wait/(remaining_ops+1)` | O | **O (정확형)** |

- **P2의 `max(0, machine_free-arrival)`은 P3의 `max(arrival,machine_free)`와 수학적으로 동일**한 통찰:
  `max(a,m) = a + max(0, m-a)`. 즉 P2·P3는 같은 원리를 다른 표기로 재발견.
- P1은 max 결합은 안 썼지만 `machine_free/(agv_free+1)` 벌점으로 기계 가용을 반영. **3회 모두 기계
  가용을 어떤 형태로든 규칙에 넣음.**
- 공통점: 3회 모두 `empty_travel`(공차) 벌점 포함.

## 3. test 결과 (33 held-out, GA 60x60 시드2)

test 평균: D1=5024.9, D2=5096.7, P1=4984.2, P2=4977.3, P3=5028.9

| run | motif | test평균 | vs D1 | vs D2 |
|---|---|---|---|---|
| P1 | X | 4984.2 | 21/33, p=0.0764 (경계) | 21/33, **p=0.0047** |
| P2 | O | 4977.3 | 21/33, **p=0.0354** | 25/33, **p=0.0004** |
| P3 | O | 5028.9 | 16/33, p=0.6057 (못이김) | 20/33, p=0.0650 (경계) |

- **D2 대비**: 2/3 유의(P1,P2) + 1 경계(P3). **비교적 robust하게 이김.**
- **D1 대비**: 1/3만 유의(P2). P1 경계, P3는 16/33으로 사실상 못 이김. **재현 안 됨.**
- "양쪽 다 유의": **P2 하나뿐**.
- 흥미로운 역설: **P3는 정확한 motif를 가졌는데 성능 최하**(D1을 16/33). motif 존재가 성능을 보장하진
  않음 - 주변 항 구성이 중요. 실제로 최고는 P2(motif 등가형 + 공차 + 대기 항의 균형).

## 4. 정직한 해석

**말할 수 있는 것**:
- **LLM이 해석 가능한 물리 통찰(기계 가용 결합)을 run마다 독립적으로 재발견한다.** 이 질적 재현성이
  이 방법의 진짜 강점 - 블랙박스가 아니라 "왜 좋은지" 설명되는 규칙을 안정적으로 찾음.
- 진화 규칙이 **D2를 비교적 안정적으로 이긴다**(3회 중 2 유의 + 1 경계).

**말할 수 없는 것(본 캠페인에서 과했던 주장 정정)**:
- "단일 진화 규칙이 D1·D2를 **양쪽 다 유의하게** 이긴다"는 **재현 안 됨**(3회 중 1회). 본 캠페인의
  P는 운 좋은 run이었다. D1을 이기는 것은 현재 예산에서 robust하지 않다.

**교란 변수(양쪽에 정직)**:
- 이번 test 예산이 가벼워(60x60/시드2) 노이즈가 큼. D1 평균이 본 캠페인 4941 -> 여기 5025로 올라간 것도
  같은 이유. **가벼운 GA가 D1 우위를 노이즈로 씻었을 가능성**을 배제 못 함. 반대로 본 캠페인의 고예산이
  우연히 D1 우위를 부각했을 수도. 어느 쪽인지는 §5.1로 판별.

## 5. 다음 단계

### 5.1 교란 제거(최우선, 저비용): 동일 고예산 재평가
P_main(본 캠페인) + P1/P2/P3를 **하나의 고예산(GA 80x80, 시드 3~5)**으로 재평가. D1 우위가 예산에
민감한지 판별. 여기서 D1을 못 이기면 "D2는 이기나 D1은 아직"이 확정 결론.

### 5.2 진화 예산·횟수 확대
K=5~10회, 진화 pop/세대 확대. P가 D1을 이기는 비율의 실제 분포를 봐야 함. 지금 1/3은 표본이 작음.

### 5.3 규칙 선택 프로토콜 확정
단일 run을 보고하면 안 됨(cherry-pick 위험). **validation split으로 여러 run 중 최선을 고르고 test로
보고**하는 프로토콜을 못박아야 논문 방어 가능. 또는 K회 중앙값/분포를 보고.

### 5.4 ablation
`max(arrival, machine_free)` 항만 D1에 수동으로 얹은 규칙 vs 전체 P. 개선이 이 항에서 오는지, 주변 항이
얼마나 기여하는지 분해(P3가 motif 있어도 약했던 점을 설명하려면 필요).
