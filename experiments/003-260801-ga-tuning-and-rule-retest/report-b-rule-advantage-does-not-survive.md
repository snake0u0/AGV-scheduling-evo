## 결론

1. **pop70에서 관측된 "진화 규칙이 문헌 디코딩을 이긴다"는 pop1000에서 사라진다.**
   같은 8케이스·같은 시드에서 P2는 pop70일 때 D1보다 **4.66%p 앞섰는데**,
   pop1000에서는 **0.26%p 뒤진다.** 문헌 규칙 D2가 5개 중 1등이다.
   짝지은 Wilcoxon 검정에서 진화 규칙 대 문헌 규칙 6쌍 전부 **유의하지 않다**(p=0.40~0.79).

2. **2x2 ablation의 귀속도 무너진다.** 공차(empty_travel) 벌점의 주효과가
   pop70에서 p=0.0001이었는데 pop1000에서는 **1.27%p, p=0.063**으로 유의성을 잃는다.
   상호작용은 **0.02%p**로 사실상 0이다(pop70에서 p=0.018).
   방향은 남아 있다(dead vs base 24쌍 중 16승) - **없어진 게 아니라 노이즈 바닥으로 내려앉았다.**

3. **규칙 간 차이가 시드 노이즈와 같은 크기다.** 케이스별 규칙 간 폭이 1.1~4.2%p인데
   시드 표준편차가 0.7~2.9%p다. 6케이스 중 2케이스는 시드 노이즈가 규칙 차이보다 크다.

4. **반드시 함께 읽어야 할 단서**: 여기서 평가한 규칙들은 **pop70에서 진화된 것**이다.
   즉 이 실험이 검정한 것은 "약한 solver용으로 최적화된 규칙이 강한 solver로 전이되는가"이고,
   **"강한 solver에서 진화시키면 어떻게 되는가"는 아직 한 번도 안 해봤다.**
   방법에 대한 공정한 검정이 아니다.

5. **좋은 소식 하나**: 우리 격차의 정직한 값이 크게 내려갔다.
   8케이스 평균 **16.7%** (Dauzere 6케이스 21.1%, Deroussi 2케이스 3.4%).
   `2026-07-29`가 보고한 65%는 pop70 산물이었다.

## Q2. 2x2 ablation 재측정

| | 결합 없음 | 결합 있음 |
|---|---|---|
| **공차벌점 없음** | 18.22% | 18.62% |
| **공차벌점 있음** | **16.94%** | 17.35% |

| 효과 | pop1000 | pop70 (2026-07-24) |
|---|---|---|
| 공차 주효과 | **+1.27%p** (p=0.063) | 유의 (p=0.0001) |
| 결합 주효과 | -0.40%p (p=0.360) | 무효 (p=0.62) |
| **상호작용** | **+0.02%p** | 유의 (p=0.018) |

| 짝지은 비교 | 결과 |
|---|---|
| dead vs base | 16승 3무 / 24, p=0.063 |
| couple vs base | 8승 4무 / 24, p=0.360 |
| both vs base | 16승 2무 / 24, p=0.105 |
| both vs dead | 11승 / 24, p=0.484 |

**공차 벌점의 방향은 살아남았다**(24쌍 중 16승, 1.27%p). 유의성은 잃었지만 우연으로 보기는
어렵다. 반면 **"결합과의 상승작용"은 완전히 사라졌다**(0.02%p). pop70 ablation의
"결합은 상보적 정제항"이라는 서술은 더 이상 지지되지 않는다.

## 왜 이런 일이 생기는가

가장 그럴듯한 기제는 **강한 메타휴리스틱이 부품 휴리스틱의 기여를 흡수한다**는 것이다.
pop1000 x 427세대의 GA는 AGV 규칙이 다소 나빠도 OS/MS를 조정해 보상할 수 있다.
pop70에서는 탐색이 약해서 규칙이 더 많은 일을 떠맡고, 그래서 규칙 차이가 크게 보였다.

이건 이 프로젝트만의 문제가 아니라 부품형 휴리스틱 연구 전반에서 알려진 현상이다.
**"어떤 solver 위에서 쟀는가"를 밝히지 않은 규칙 비교는 재현되지 않는다.**

## 그러나 방법이 기각된 것은 아니다 - 세 가지 이유

1. **여기 규칙들은 pop70에서 진화됐다.** 약한 solver에 맞춰 최적화된 규칙을 강한 solver에
   가져다 쓴 결과다. **강한 solver에서 진화시킨 적이 한 번도 없다.** 이게 공정한 검정이며
   아직 미실시다.

2. **이 실험은 슬롯 3(AGV 선택) 하나만 바꿨다.** 슬롯 1(기계 선택)·2(공정 순서)는 여전히
   GA 염색체다. 그런데 우리가 실측한 병목은 **기계 선택**이다(01a 0.5% vs 15a 38%).
   즉 이 결과는 **"AGV 슬롯 하나로는 부족하다"**는 뜻이고, 2026-07-31에 확정한
   **5슬롯 설계의 전제와 정확히 일치한다.**

3. **저예산에서는 규칙 차이가 컸다.** pop70·10초에서 P2와 D2의 차이가 6.26%p였다.
   규칙이 중요해지는 영역이 따로 있을 가능성이 있고, 그건 **빠른 의사결정이 필요한
   동적·온라인 환경**의 논거가 된다(보류 중인 A안의 프레이밍).

## 다음 - 우선순위가 바뀐다

1. **[최우선] 튜닝된 설정에서 진화시킨다.** 600초 x pop1000을 적합도로 써서 LLM 진화를
   실제로 돌린다. 여기서 D1/D2를 이기는 규칙이 나오면 주장이 복구되고, **강한 solver 위에서
   얻은 것이므로 이전보다 훨씬 강한 결과**가 된다. 안 나오면 슬롯 3만으로는 안 된다는 게
   확정되고 5슬롯 설계의 근거가 된다. 어느 쪽이든 답이 나온다.
   - 다만 적합도 1회가 600초라 진화 비용이 큼. **캐스케이드와 예산 설계를 먼저 정해야 한다.**
2. **규칙이 중요해지는 예산 구간을 찾는다.** 10초 / 60초 / 600초 x 각 예산의 최적 population
   에서 규칙 간 차이의 크기를 잰다. "규칙은 저예산에서 중요하다"가 성립하면 논문의 링이
   그쪽으로 이동한다.
3. 예산 곡선 3600초 연장 (LNS 판정) - 우선순위 하락. 지금은 규칙 쪽이 더 급하다.

## 주의

- 8케이스 x 3시드 = 24쌍이다. 효과 크기가 1%p 수준이면 이 표본으로는 검출력이 부족하다.
  "유의하지 않다"는 "차이가 없다"가 아니라 **"이 표본에서 구분되지 않는다"**이다.
  다만 pop70에서는 같은 표본으로 4.66%p 차이가 잡혔으므로, **효과가 크게 줄었다는 것 자체는 확실하다.**
- pop1000은 2026-08-01 기준 최적이지만 격자가 성기다(70/300/1000/3000/10000).
